# Dashboard

A live board of the Goa and Portugal chapters. The data lives in Google Sheets;
the app reads them and updates itself the moment someone saves.

## How the live update works

There is no polling anywhere.

1. An editor saves a chapter's Google Sheet.
2. An Apps Script bound to that sheet POSTs to `/api/sheets/changed`.
3. That route expires the cached CSV (`revalidateTag("sheets", { expire: 0 })`)
   and bumps one row in the `sync_state` table.
4. Every open board is subscribed to that row through Supabase Realtime, so it
   re-renders within about a second and pulls the new rows.

While nothing changes, nothing is requested. A 5 minute revalidate on the fetch
is only a safety net in case a webhook is ever missed.

## Setup

### 1. Environment

Copy `.env.example` to `.env` and fill it in. The same values go into Vercel.

Two Postgres URLs, and they are not interchangeable:

- `DATABASE_URL` — transaction pooler, port **6543**, used by the running app.
- `DIRECT_URL` — session pooler, port **5432**, used by the Prisma CLI.

Pointing the CLI at 6543 makes `prisma db push` connect and then hang forever,
because the schema engine needs session-level advisory locks.

### 2. Database

```bash
npx prisma db push
npx prisma generate
```

`sync_state` additionally needs Realtime turned on, once:

```sql
alter table sync_state replica identity full;
alter publication supabase_realtime add table sync_state;
alter table sync_state enable row level security;
create policy sync_state_read on sync_state
  for select to anon, authenticated using (true);
grant select on sync_state to anon, authenticated;
```

### 3. First admin

Visit `/admin/setup`. It is open only while no admin exists and closes itself
after the first account is created. Everyone signs in at `/admin/login`
afterwards. Auth is a Supabase JWT in a cookie; a valid token is not enough,
the user id must also appear in `admin_users`.

### 4. Sheets

The workbooks in `excel/` are generated by `python scripts/generate_excel.py`.

1. Upload both to Google Drive.
2. Open each and **File → Save as Google Sheets** (an uploaded `.xlsx` is not a
   Google Sheet and cannot be read).
3. Share each as **Anyone with the link → Viewer**.
4. Paste the links into `/admin`.

### 5. Live updates

In each sheet: **Extensions → Apps Script**, paste
`scripts/apps-script/notify-dashboard.gs`, set `WEBHOOK_URL` and
`WEBHOOK_SECRET`, then run `installTrigger()` once and approve the prompt.

## Deploying to Vercel

Import the repo, set the environment variables from `.env.example`, deploy.
`postinstall` runs `prisma generate`, which Vercel needs because it caches
`node_modules` between builds.

The board renders per request (`force-dynamic`), so no CDN copy is ever served
stale.

## Local development

```bash
npm run dev
```

If a Tailwind class you just added does nothing, the Turbopack cache is stale:

```bash
rm -rf .next && npm run dev
```
